# 🎓 Placement Vault

Placement Vault is a Django-based web application designed to help students prepare for campus placements by sharing and exploring interview experiences. The platform provides a centralized place where students can discover company-wise interview rounds, schedules, and experiences contributed by other students.

---

## ✨ Features

* 🔐 User Registration & Login
* 🏢 Browse companies
* 💼 View company roles
* 📝 Publish placement experiences
* 📅 Add and manage interview schedules
* ✏️ Edit placement experiences
* 🔍 Search companies
* 📱 Responsive and user-friendly interface

# 🚀 Installation

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PlacementVault.git
```

## 2. Navigate to the project folder

```bash
cd PlacementVault
```

## 3. Create a virtual environment

```bash
python -m venv venv
```

## 4. Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/macOS

```bash
source venv/bin/activate
```

## 5. Install dependencies

```bash
pip install -r requirements.txt
```

## 6. Apply database migrations

```bash
python manage.py migrate
```

## 7. Start the development server

```bash
python manage.py runserver
```

Visit:

```text
http://127.0.0.1:8000/
```
